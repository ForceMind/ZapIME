## 开始使用

1. 安装适合设备架构的产品 APK。
2. 打开闪电输入法首页，依次使用“1 启用闪电输入法”“2 切换到闪电输入法”。
3. 在“键盘与反馈 → 中文候选”中查看“离线候选增强”。新偏好缺省为开启；用户主动保存的关闭选择会保留。
4. 在普通文本输入框输入全拼，例如 `shijie`。基础候选立即显示，后台模型随后根据当前输入上下文调整符合精确读音的已有候选。

8M 模型约 8.2 MB；权重、词表、元数据和来源说明合计 8,323,716 字节，已随产品打包。无需配置模型 API Key，也无需单独下载这个候选模型。离线语音继续使用原来的独立模型导入流程。

## 当前行为

- **保持正常输入速度路径。** 基础候选先显示，模型任务在独立有界 worker 运行。过期/超时结果丢弃，资源或模型不可用时继续使用基础候选。
- **只调整已有候选。** MSIME 仍负责拼音解码、候选生成、选择、学习和上屏；模型返回候选 ID 的排列。个人置顶、补全、模糊/纠错、部分上屏保留原规则，首版增强限精确读音候选。
- **保留点击身份。** 候选点击、空格、九键读音与置顶绑定原候选 ID 和组字版本，处理后台排序与界面刷新之间的竞态。
- **仅使用本次输入会话的有限上下文。** 上下文最多 64 个 Unicode 码点；切换、隐藏、发送或位置不确定时清除。密码、私密、禁止学习、无建议和搜索场景跳过增强。输入内容不上传，也不保存成模型聊天历史。
