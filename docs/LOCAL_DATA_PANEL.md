# 键盘内本机资料面板

Android 工具栏的剪贴板图标打开「本机资料面板」，可查看全部资料、快捷短语、永久收藏和本机剪贴板。只读本机 SQLite，不发网络请求，不增加 R2 读写。本文说明源码行为；构建与系统输入验证以 STATUS.md 的具体提交和 CI 为准。

## 使用与生命周期

- 点击条目将完整正文插入当前输入框；列表只显示有界预览。
- 搜索支持正文、标题、短语编码和标签。每页最多显示 20 条，提供上下页。
- 剪贴板仅在点击「保存剪贴板」时读取纯文字，不监听系统剪贴板变化、不解析 URI。临时条目保存 7 天，系统标记为敏感的内容拒绝保存。
- 剪贴板置顶仅改变排序，仍按原时间过期。「转为收藏」创建独立永久副本；删除原剪贴板不删除收藏。
- 删除需在当前条目上再次确认；逻辑删除和过期过滤不代表安全擦除。
- 密码、数字/电话等私密输入及 NO_PERSONALIZED_LEARNING 字段不打开资料面板，也不加载个人库。

搜索不使用会抢走宿主焦点的 EditText。键盘开一个独立、不学习、不加载个人库的 Rust 输入会话，候选选择写入搜索词缓冲区。英文和中文都通过这个缓冲区查找，不调用目标输入框的 commitText/setComposingText。完成搜索回列表，取消恢复之前的搜索词。搜索使用全键布局，不改变用户的九键偏好。

所有 Rust 句柄继续归串行 worker 所有。搜索与正文请求捕获各自目标，返回时检查输入框 epoch；资料回调同时检查面板实例。失焦会清空搜索状态并关闭独立会话，不能把迟到的搜索结果写到新输入框。搜索候选不提供个人候选置顶。

## 共享核心请求

这些接口是本地 C ABI JSON 请求，不是云同步协议。

| op | 请求字段 | 行为 |
| --- | --- | --- |
| personal_query | kind、query、offset、limit | 最新本机快照；不改变组字或候选 generation |
| personal_commit | id、expected_revision | 从库重新取完整正文，修订匹配且未过期/删除才提交；组字未结束时拒绝 |
| personal_action | id、expected_revision、operation_id、action | 修订校验后 pin/unpin/delete/favorite；favorite 另需 destination_id |

query 最长 512 UTF-8 字节，limit 为 1–40，默认 20。kind 为 all/snippet/favorite/clipboard。返回 items、total、offset、next_offset；单个 item 含 id、revision、type、label（最多 40 个字符）、preview（最多 96 个字符）、pinned、expires_at_ms，不返回完整正文。排序为置顶优先，再按类型、剪贴板期限、标题及 UUID 稳定排序。

每次查询读取当前 SQLite 的记录，不以输入会话启动时的缓存作为列表。此读取不更新候选缓存，避免不增加 generation 却改变可见候选映射。实际编辑后刷新候选缓存并递增 generation。点击时按记录 ID 和预期 revision 复核，拒绝陈旧条目；原始正文不会由 Java 预览拼回。

临时剪贴板过期后立即从查询和插入中排除，包含已置顶条目；永久收藏没有过期字段。当前没有后台清理、自动捕获、容量淘汰或云端跨设备插入。Android 搜索词最多 128 个码点，正文保存仍受共享存储的 64 KiB UTF-8 限制。

变更沿用 Store.edit 的记录/操作同事务持久化及本地修订语义。界面不自动重试变更；新操作生成新 UUID，连续点击由面板拦截，发生冲突则刷新列表。不能将高层个人资料动作接口等同于服务端请求幂等协议。

## 验证与限制

Rust personal_panel 测试覆盖 Unicode/标签/编码搜索、40+5 分页、有界预览与完整插入、外部连接修改/删除、陈旧修订、过期置顶、永久副本、重开恢复、私密拒绝，以及查询不改变组字/候选代次。

Android 专用验收新增面板内插入、英文/中文搜索隔离、显式合成剪贴板保存、敏感标记拒绝、置顶/取消置顶、收藏、删除、失焦和 NO_PERSONALIZED_LEARNING 拒绝。保留两轮独立输入、真实服务退出及 fatal 拒绝，不以 APK 编译代替系统输入。原生截图由 CI 直接保存，全部内容为合成文本。

查询目前读取并排序本机记录集合，再返回有界分页；十万条资料的延迟、数据库索引和增量检索仍需专项优化。SQLite 记录与开放归档仍含明文。其他三端资料面板、加密恢复 UI、四端联网客户端和完整剪贴板设置未完成。
