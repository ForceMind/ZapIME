# ZapIME v0.1.0-alpha.1 · Source Alpha / 源码预发布

这是首个整理后的源码 Alpha 发布入口，集中当前已有工程与验收记录。Android 仍处于开发阶段，macOS、iOS、Windows 为原生开发宿主。这个标签不改变历史 APK 的 `0.1.0-dev` 版本或开发签名。

## 本次内容

- Android 原生全键/九键、个人资料、明暗主题与系统触感。
- 固定 MSIME + 8M 本机候选模型，默认增强、空可信上下文保守回退、异步有界调度与稳定候选 ID。
- 34 条冻结合成语料与基础排序对照、真实生产词库/模型、两版 ORT 主机评测及保留的失败证据。
- X-ASR 与可选 VoiceKey 离线适配器、固定模型导入、录音预览/确认及取消生命周期。
- Android 显式手动密文同步和可自建 Go/PostgreSQL 服务；本机备份、同步恢复材料与服务凭据独立管理。
- 中英文首页、贡献及行为约定、问题模板、文档导航、路线图和持续研发接管入口。

## 获取精确源码

```sh
git clone --branch v0.1.0-alpha.1 --recurse-submodules https://github.com/ForceMind/ZapIME.git
cd ZapIME
python3 scripts/verify_upstream.py
```

Release 附件是根 Git 树的源码包、`metadata.json` 与 `SHA256SUMS`；元数据记录准确提交、tree 和子模块 Gitlink。**源码包与 GitHub 自动源码下载都不含两个子模块内容**；完整构建使用上面的递归 clone。附件不含模型权重、APK、编译缓存或签名密钥。按各组件原许可获取子模块，勿用上游最新分支替换固定提交。

Rust 1.97.1；Android JDK17/API36/build-tools35.0.0/NDK28.2.13676358。详见[构建](https://github.com/ForceMind/ZapIME/blob/v0.1.0-alpha.1/docs/BUILD.md)、[许可审计](https://github.com/ForceMind/ZapIME/blob/v0.1.0-alpha.1/docs/LICENSE_AUDIT.md)与[发布流程](https://github.com/ForceMind/ZapIME/blob/v0.1.0-alpha.1/docs/RELEASING.md)。

## 验证身份与限制

发布整理前的功能/文档基线 `5d976f578a2b11d14b9050ff0ec01e5d18d9e538` 七条 workflow 全部成功：候选 [42407415284](https://github.com/ForceMind/ZapIME/actions/runs/42407415284)、完整 Android [42407415282](https://github.com/ForceMind/ZapIME/actions/runs/42407415282)、VoiceKey [42407415283](https://github.com/ForceMind/ZapIME/actions/runs/42407415283)、共享/Apple [42407415237](https://github.com/ForceMind/ZapIME/actions/runs/42407415237)、Windows [42407415301](https://github.com/ForceMind/ZapIME/actions/runs/42407415301)、同步 [42407415255](https://github.com/ForceMind/ZapIME/actions/runs/42407415255)和语音 CPU [42407415336](https://github.com/ForceMind/ZapIME/actions/runs/42407415336)。这些是该固定提交的结果；Release 元数据和新流水线记录发布源码的实际身份，不能把历史 CI 冒充新提交的全量验收。

候选专项 API28/35/36 包含真实模型/JNI及独立系统 IME/Editable 门禁。先前 API35 一次种子提交后的组字异常仍保留，后续成功不证明唯一根因已解决。34 条人为语料及主机 RSS/延迟不代表自然输入质量、手机性能或能耗。

整合首轮 run42440405925 的 VoiceKey API28/35/36 专项均通过，但其独立 API28 同步恢复页在 actual SAF open / IOException 失败；之前的导出、native 身份和确认通过，清理成功不能替代恢复 UI 通过。根因未确认，原安全记录保留在 [发布期失败证据](https://github.com/ForceMind/ZapIME/blob/v0.1.0-alpha.1/docs/evidence/source-release-ci-20261107/voicekey-first/README.md)。

尚未完成 ARM/S25、自然语音、长期稳定性、正式签名和无损升级。macOS TIS/IMK、Windows 独立 profile/实际激活与 iOS 真机键盘分别未验收；四端同步、设备配对、冲突处理及完整灾备尚未闭环。
