# 技术决策

## ADR-013 · 2026-10-23 · 用户截图布局与系统触感

Android 九键按用户提供的 QQ 明暗截图重新实现：独立标点侧栏、三行九宫格、右侧退格/重输/表情、底部中英/符号/宽空格/数字/回车。键帽数字置顶，主题跟随系统或本机显式选择；Canvas 字形及图标为独立实现，不复制 QQ 皮肤、头像或开源项目代码。保留 MSIME 固定解码器与代次隔离。

按键使用 View.performHapticFeedback(KEYBOARD_TAP)，不绕过系统设置，不申请 VIBRATE 权限；应用开关默认开启、声音默认关闭。退格按下删除一次，380ms 后每 65ms 重复，重复不叠加震动；抬手/取消/移出/多指/面板销毁/失焦/隐藏均取消。模拟器只能验证事件与开关，不能验收马达手感。麦克风未集成时不显示假语音入口；原生录音接入仍由 #24 跟踪。退格使用有界 ICU 字素边界，避免心形变体符、肤色、旗帜、ZWJ 家庭和重音只删掉一个码点；边界不确定时交回编辑器处理。

## ADR-012 · 2026-10-23 · 复用九键与先验证本地语音

九键通过现有固定输入引擎开放数字组码、读音消歧和代次控制，Android 保存独立本机布局，英文/密码不误入数字拼音。个人词按整段编码匹配并遵守锁定读音，不重写拼音解码器。共享 ABI 只增加 JSON 字段/操作，不改变旧操作和二进制接口。

本地语音先以独立、固定校验值的 sherpa-onnx/X-ASR CPU 探针验证原生推理和断网边界；识别性能与准确率分开。合成器样例误识别必须保留，不把非空输出当普通话准确率验收。模型不随当前 APK 或服务分发，不默认云端回退/录音上传。Android/桌面后续接本地录音与焦点绑定，iOS 使用合规主 App 辅助流程；不能以完整访问绕过键盘麦克风限制。

## ADR-011 · 2026-10-23 · 本地优先与可丢弃的服务端密文缓存

R2 是持久密文存储；正常输入与本地检索不调用云端。在线服务在数据库鉴权/修订索引之后使用 16 MiB、10 分钟 LRU 缓存及同键并发读取合并，成功写入预热；写入确认始终要求后端成功。缓存只含按账号和 SHA 定位、验证过的不可变对象，不缓存错误，不绕过撤销或推送前置检查。重启、过期或淘汰后回源。

管理备份/恢复/验证命令不使用缓存，确保检测真实持久对象。在线缓存可能短暂掩盖外部误删，故不能代替后端校验。客户端网络尚未接入；防抖、净变化合并、增量、退避与场景刷新在 SYNC_EFFICIENCY.md 明确为待实施规则。HTTP 批量发送不会自动减少当前每 Change 一个对象的 R2 操作数；对象打包和增量备份另行验收，不在本切片伪称完成。

## ADR-001 · 2026-10-20 · 固定上游，渐进迁移

MSIME 使用精确提交的 Git submodule 保留完整可追溯源树与四端原生宿主；ZapIME 扩展位于根工作区，不批量改写上游源码。首个 Android 验证宿主为独立原生 InputMethodService，复用原拼音引擎 Session，不携带上游联网服务。候选代次由薄适配层核验。

这让离线核心和独立标识可以先实际构建，代价是首包不包含上游成熟键盘的所有功能。M1 仍须逐步移植上游输入运行时、键盘交互与其余宿主；四端不会因 submodule 存在而被标为完成。

## ADR-002 · Android 身份与默认网络边界

使用 org.zapime.android，与上游 app.msime.android 隔离。首个开发包无 INTERNET 权限，不运行账号、更新或资源下载服务。构建时获取校验过的拼音与英文词库，运行时离线。临时不提供模型权重、语音、辅助码、剪贴板。

## ADR-003 · 后端独立实现

msime-cloud 未发现覆盖第一方实现的明确授权。只记录协议观察，不复制实现。后续自建服务独立开发，使用客户端密文、设备认证与基于修订的冲突处理。

## ADR-004 · 统一数据与恢复封装

共享 SQLite 采用事务修订与操作幂等，开放归档采用显式明文格式。恢复包在外层使用 RustCrypto XChaCha20-Poly1305 和固定资源参数的 Argon2id，同时封装根密钥与归档。恢复码独立保存，服务器不掌握解密后门。模块级恢复演练先于云端接入；不把它标作四端或空服务器恢复验收。

## ADR-005 · 2026-10-22 · 公开授权与 Apple 最小原生宿主

用户明确要求保持 Public，覆盖早期 Private 约定。继续禁止提交凭据和真实输入记录，不修改既有许可义务。

macOS 与 iOS 通过版本 1 的有界 C ABI 调用现有 ZapIME InputSession，保留 MSIME 固定引擎。宿主身份、缓存和资料路径均独立；未批量修改 vendor。macOS 使用 InputMethodKit，iOS 使用 UIInputViewController 原生扩展。先保留不学习的离线模式，不引入上游账号/网络服务，也不把共享库检查当作宿主验收。iOS 通过专用 Thread 保持 Rust 会话线程归属，主线程只渲染状态及操作文本代理；焦点代次过滤迟到结果。

本切片以原生编译和桥接测试为门禁；系统激活、真实应用输入、键盘扩展内存、签名与分发仍需单独验证。

## ADR-006 · 2026-10-22 · Windows 原生隔离边界

上游完整 Windows TSF 与独立 Server、配置、云端协议及品牌版表绑定。首个 ZapIME Windows 切片采用最小原生 TSF/COM 宿主直接调用同一个有界 C ABI，解码器不重写；研究上游工厂生命周期、编辑锁和注册回滚，保留固定子模块供后续成熟交互迁移。仅声明实际实现的 keyboard category，关闭学习和联网，不提前声明安全桌面/UILess 等能力。

CI 在 Windows SDK 下编译真实 DLL，并装载工厂和核心进行边界测试。未经系统安装和真实客户端输入验收，不将其记作完整 Windows 输入法完成，也不将新的最小宿主等同于上游全部成熟功能。nlohmann/json 固定 v3.12.0 和归档 SHA-256，保留 MIT 文本。

## ADR-007 · 2026-10-22 · 独立密文服务与事务同步基线

服务端从空白实现，不复制未获明确许可的 msime-cloud。优先用 Go/PostgreSQL 的账号行锁建立可验证的线性修订、幂等与撤销；不以本机时钟覆盖冲突。服务仅处理 zapime-crypto v1 envelope，服务访问凭据与 E2EE 解密材料分离。初期账号/凭据通过管理员 CLI 管理，不伪装成已完成图形账号和双设备核对码配对。

先验证真实数据库、Docker、两设备密文交换和空数据库恢复，随后才接四端异步客户端。备份脚本不覆盖已有文件；恢复拒绝非空库。账号保守配额满时拒绝写入，不自动删除收藏或墓碑。生产前仍需速率限制、监控、安全审计、密钥托管与设备配对。

## ADR-008 · 2026-10-22 · 不可变上传请求与独立修订

SQLite v2 为离线操作引入显式持久自增序列，避免以 VACUUM 后可能改变的隐式 rowid 作为上传顺序。待发正文取自创建操作时的快照，不能在重试时替换成记录的后续编辑。首次 AEAD 密文请求持久化后原样重试，避免同一 operation_id 因重新随机生成 nonce 被服务端拒绝。

本地记录修订、服务端实体修订和账号拉取游标分开保存。上传确认只原子更新待发状态、确认凭据与服务端实体修订，不覆盖业务记录，也不推进拉取游标；否则可能跳过其他设备的并发写入。账号绑定阻止跨账号误上传。远端认证应用、冲突解决和游标原子推进另行实现，不以这些准备接口冒充已联网的同步客户端。

SQLite 内部版本升级与开放归档版本独立；旧程序拒绝打开 v2，降级需先导出开放归档并恢复到旧版全新库。新增密文暂存不改变本地 records/operations 仍含明文的事实，完整静态加密与安全清除仍待实现。

## ADR-009 · 2026-10-22 · 原生键盘设计与退出验收

按用户要求参考 QQ 输入法的紧凑布局，Android 采用四排键位、共用工具/候选区域与独立数字/符号面板；图标由 ZapIME 自行用 Canvas 绘制，不引入第三方皮肤、QQ 标识或联网入口。设置与个人资料使用同一组原生视觉组件。新 UI 不改变 Rust 输入核心、焦点代次与候选代次校验。

原生截图和输入断言不能替代运行时日志复核。UI 改造的首次两轮输入 PASS 后，日志暴露既有 onDestroy 生命周期顺序错误：父类 onDestroy 同步进入 onFinishInput 时，worker 已经 shutdown。必须先完成父类回调，再在核心所属线程关闭 handle 和 worker；关闭动作清零 handle，避免重复释放。CI 在受保护的临时模拟器里按轮清空旧日志、切回 AOSP 输入法、确认服务退出并拒绝本轮 ZapIME fatal。不能把清空日志扩展到用户日常设备。

## ADR-010 · 2026-10-22 · 自有服务器中转与私有 R2

用户要求一条命令部署，自有服务器中转，Cloudflare 免费空间保存云资料。选择 R2 Standard 私有桶和 S3 兼容接口；账号、授权和事务修订留在自己的 PostgreSQL，密文正文外置。使用固定官方 AWS SDK v2 的 SigV4，不设计自创签名。访问密钥只留服务器配置，E2EE 根密钥继续由客户端持有。

对象以账号 + SHA-256 寻址，条件创建且读取校验内容。事务先复核授权/幂等/条件修订/配额，再上传对象，最后提交索引；外部失败不推进修订，提交失败允许留下无引用对象，不自动删除可能仍需的历史。Pull 最大八路读取，任何对象缺失或校验失败整页失败。schema v2 自动接受 v1 内联记录并阻止旧二进制降级；配置缺失时拒绝外置数据库静默降回内联。

备份先 pg_dump，再导出追加写对象的标准 tar 超集；恢复拒绝非空库，导入后验证所有引用再启动。跨 PostgreSQL 和 S3 的恢复不是单事务，失败须保持服务停止并幂等重试对象导入。部署器保留版本、配置、升级前成套备份，自动 HTTPS；已有反代模式不抢占其他进程端口。免费额度是 Cloudflare 账号计量规则，不能承诺无限免费或本服务硬性阻断所有超额计费。

## ADR-012 · 2026-10-24 · 本机资料与独立搜索输入

键盘资料面板用最新只读快照，而不是输入会话缓存；查询不改变候选映射/代次，点击按 ID/revision/期限重新取完整正文。SQLite 执行过滤、索引排序和分页，Rust 只物化有界摘要；Android 用独立 reader 和进度预算，陈旧排队查询被替换，不把大库扫描塞到输入队列。辅助索引兼容 v2，不改公开归档。

在 IME 内使用不学习、无个人库的独立输入会话与查询缓冲区，保留宿主焦点并支持中文候选；查询词不进目标 InputConnection。输入句柄继续由原 worker 所有，epoch/面板/查询序号过滤迟到结果，清空按排队输入顺序执行，组字时保留完成/取消。隐私输入不开放资料面板。

剪贴板默认不监听，只在显式保存时读取纯文字，系统敏感标记拒绝；置顶不延长临时期限，收藏创建永久副本。面板没有联网或自动上传，也没有将逻辑删除宣传为安全擦除。

## ADR-013 · 2026-10-24 · 调度与持久队列分离

共享调度器只接收单调经过时间、持久编辑事件和经过验证的完成结果，不持有正文/凭据，不调用网络，也不修改队列或 cursor。默认关闭，启用、联网、前台和授权四个门槛共同控制；在途拉取共享触发，上传时的新编辑保留。采用 2 秒防抖/30 秒上限、60–300 秒增量检查、面板 5 秒冷却及有界抖动退避；Retry-After 不被手动刷新/重连绕过，401/403 须显式重授权。

进程重启从持久队列重建信号，不保存跨进程单调时钟值；后台不以固定周期轮询承诺替代平台作业。宿主必须先验证认证密文并原子落库，才能报告成功。此模块尚未集成，不伪称四端同步已完成。

## ADR-014 · 2026-10-24 · 冻结前合并待发编辑

重复编辑合并只操作尚未 stage_upload 的有界窗口，在 IMMEDIATE 事务中使同记录旧操作不再 pending，保留最后操作和最终墓碑；不改/删 request/result 历史、记录修订、冻结密文或确认凭据。每次最多考察 4096 个未暂存操作，不保证一次消除全部历史重复或与远端相同的正文。

发送前必须持久暂存，已暂存即按可能已经发出处理，丢响应后原样重试，不能因新编辑而重写 nonce/密钥/正文或跳过冲突。并发合并使旧快照无法再暂存时，发送方须重读队列。pending=0 只表示不再待发，服务器确认另看 ack_revision；本地 revision、服务器 revision 和拉取 cursor 继续分离。合并不降低历史备份读数，也不是安全擦除；宿主接入和实际用量另行验收。
