# 开发路线与验收

更新：2026-11-07。这里区分已有实现与剩余交付；精确事实见 [STATUS](STATUS.md)。

| 阶段 | 当前状态 | 下一项可验证交付 |
| --- | --- | --- |
| 中文候选 C0 | Android 固定引擎、默认离线增强及空上下文保护已实现 | 维护候选身份、隐私、取消和系统 IME 回归 |
| 质量与资源 C1 | 34 条冻结合成语料、配对指标和两版 ORT 主机基线已完成 | 先冻结更广语料；分别归因候选缺失/重排错误；集中 ARM 资源验收 |
| Android 稳定性 | API28/35/36 多条专项成功；历史 API35 间歇组字失败保留 | 利用新增生命周期诊断定位复现，保留原失败且不放宽断言 |
| 双离线语音 V1/V2 | X-ASR/VoiceKey 路由、模型导入、JNI、预览确认和模拟器证据已有 | 完成同机自然语音、长会话、取消后资源释放、CER/延迟/能耗比较 |
| Android 真机 V3 | 已交付开发候选与集中检查单 | 三星 S25 上一次集中验收；正式签名及可恢复升级另行验证 |
| 手动同步 | Android 显式逐轮传输与独立 Go/PG 服务已有 | 定位 API28 SAF 恢复打开失败；手机/公网部署验收、配对、冲突处理、历史密钥与完整灾备 |
| macOS/iOS/Windows | 原生开发宿主/桥接可构建 | 各自系统激活、实际 App 上屏、安装签名；随后接候选模型/语音 |
| 英语伴学 | 策略及确认提交接缝已有，默认关闭 | 授权清楚的本机模型、真实推理 worker/UI/显式收藏；不填示例译文 |
| 公开发行 | 源码 Alpha 文档和发布流程 | 补齐 VoiceKey 分发条款、候选来源澄清、稳定签名及真机证据后再发布通用二进制 |

没有手机时继续语料、复现、诊断、共享模块及其他可执行工程，保留一次集中的设备清单。不要重复最初模型接入或已完成的语音路由；新切片从核实后的最新 main 建分支与 PR。详细阶段要求见[开发计划](DEVELOPMENT_PLAN.md)。
