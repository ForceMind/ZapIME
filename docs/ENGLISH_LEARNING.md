# 英语伴学：输入中文，同时积累英语

用户于2026-10-24提出：中文输入完成后，在显示联想候选的同时，展示本次内容的英文翻译，用日常表达学习和积累英语。

这是可选增强，不改变P0的四端输入、离线资料与可恢复同步目标。当前已有Android请求策略、接受提交短句组装和宿主事件接缝；**尚未接入翻译模型、推理worker、英语条、启用开关、收藏按钮或续词联想引擎**，不是已可使用的翻译功能。生产默认关闭且无模型，不保留伴学原文。

## 交互目标

| 位置 | 示例（人工编写的设计示意） |
| --- | --- |
| 本次已上屏中文 | 明天见。 |
| 联想候选行 | 好的 · 拜拜 · 早点休息 |
| 独立英语条 | See you tomorrow.　收藏 |

示例不是模型输出或引擎联想验收。当前Android的`renderResult()`在组字为空后显示工具栏，没有完整续词联想；联想与翻译必须分别实现，不能把示意当现成功能。

- 主动开启“英语伴学”，只展示参考英译，发送出去的中文不变。学习模式预留固定的一行，译文到达不挤动键位；拼音及候选优先，不占用数字选词编号。
- 只组合当前同一编辑器中由ZapIME成功提交的有界短句，不扫描目标App全文。短暂停顿约600ms后处理，句末标点可立即结算；不是每按一个字就排队推理。
- 第一版聚焦译文预览和显式收藏。发音、例句、复习计划属于后续增强，不先添加无真实能力的按钮。
- 收藏保留用户确认的中英对照，可先复用现有永久收藏的文字格式；不急于新增第六种同步实体。收藏动作先核对当前快照，再把不可变中英对送到存储worker，不能在写入时取成新句子。重复点击需幂等。
- 译文有歧义或错误的可能，应标为“参考英译”，保留中文原句并允许未来编辑收藏，不宣称唯一标准答案。

## 隐私与资源

默认关闭。密码、禁止学习、隐私、数字/电话/验证码、URI/邮箱和搜索上下文拒绝；面板搜索、本机资料插入、剪贴板粘贴和语音预览不因共用渲染函数就自动翻译。语音若接入，只能在用户确认插入成功后单独验收。

源句和译文默认仅保留在有界内存中，不自动写输入历史、磁盘缓存或收藏。翻译本身不产生R2读写；只有主动收藏并另行启用同步后，才规划沿用已有加密/合批策略。当前客户端收藏同步接入仍未完成。

本地模型优先、单独安装并核验来源/版本/SHA/许可，缺模型明确不可用，不自动下载或云端兜底。未来若允许云翻译，需要单独明确文字会交给哪一处理方：翻译方会接触明文，不能沿用“同步服务只见密文”的表述。当前APK仍无网络权限。

推理使用独立worker，不占用按键、语音或数据库查询worker；最多一个实际执行中请求和一个最新待处理片段。耗时或失败不能阻塞输入。这里只是内存状态释放，不承诺Java字符串被物理安全擦除。

## 本次真实源码

`EnglishLearningGate`不引用Android API或翻译SDK，没有网络、数据库、编辑器读取或界面。它由新的`EnglishLearningSession`包装，后者已有宿主调用，但生产默认关闭、无模型：

1. 默认关闭、默认编辑器不合格、默认无模型，三项都满足才接收调用方提供的已提交短句快照。
2. 源句最多256个UTF-16单元，译文最多1024；拒绝错误代理项、控制符、仅不可见字符和显式双向控制符，保留合法组合表情与重音。仅处理含汉字的源片段。
3. 600ms逻辑时钟防抖、句末即时；新快照覆盖唯一pending。旧worker未真正完成前不释放执行槽，即使已失焦或关闭功能，也不能制造无界待执行任务。
4. 请求绑定独立session/revision对象身份和调用方已核验的modelVersion；旧句、重复回调、模型变更、编辑器重启和开关往返均不得展示旧结果。
5. 展示中英对不可变；显式收藏点击只接受当前所见的Pair。策略自身不保存收藏。

策略是单一宿主线程控制的对象，worker完成后必须回投该线程。每个`takeReady()`返回的请求都须最终`complete()`：提交失败可立即结算；取消或推理异常需在实际任务停止后结算，不能提前释放仍运行模型的槽位。

宿主接缝已经实现：`send()`、交接期间暂存的`InputReply`及直接手打插入都携带入队时的独立不透明ticket，只在`commitText`返回true后组装；API的true只代表接受/转发，不能保证任意远端App最终正文完全相同。`personal_commit`显式无ticket且清空伴学；搜索只更新独立搜索会话，不从`renderResult()`采集。没有新增目标App文本读取。

**任何`onStartInput`先清空并暂停学习，包括保留拼音组字的重启路径**；`onStartInputView`重新检查声明字段资格。隐藏/失焦/配置变化/销毁暂停；观察到的外部选区/标记变化、删除/剪切/粘贴、进入资料/搜索/语音/编辑面板、编辑拒绝及核心错误使旧ticket失效。自己的正常选区回声保留当前短句。普通文本App如果未正确声明验证码或私密用途，系统没有通用标志可保证识别；同位置同长度的静默外部改文也不能由此检测。这里保存的是“本次接受提交的短句”，不是App正文镜像。

首版资格采用保守白名单：仅普通/短消息/长消息文本，拒绝未知与网页文本variation、密码、数字/电话、URI/邮箱/filter、声明搜索、NO_SUGGESTIONS、NO_PERSONALIZED_LEARNING及宿主私密状态。没有增加用户可开启但无法翻译的设置。

组装最多256个UTF-16单元，英文/标点可作为同一句的手打片段，但最终源句必须含汉字。600ms防抖，句末立即；已结束短句后新的字母/数字开始新句，超过10秒停顿也重开短句。累计超限或单片超限不截取尾部，丢弃至下一次句末或超过10秒间隔。非法Unicode/控制符、失败提交或时钟倒退清空；不是完整自然语言分句器。原文只在启用且有模型、合格可见会话中保留。

## 模型调研与许可边界

| 候选 | 核实事实 | 待验证 |
| --- | --- | --- |
| OPUS-MT/Marian中译英 + ONNX Runtime | OPUS-MT模型卡标为CC-BY-4.0；ORT为MIT并有Android/iOS原生包 | 分词/导出/encoder与decoder/past、量化一致性、现有ASR所带ORT算子和ABI能否复用 |
| 同一模型 + CTranslate2 | CT2为MIT，官方有OPUS/Marian转换路径 | 桌面基准、ARM性能；移动端NDK/JNI/Apple静态库，不能把桌面Python wheels算四端SDK |
| 本地词典或人工短语 | 可用于释义/对照和收藏体验 | 第三方资源逐份许可审计；不能冒充任意整句翻译 |

拼音候选模型与语音识别模型不是文本翻译器。产品尚未导入上述模型。后续独立Linux CPU探针已有真实转换/离线推理与语义偏差记录，见[本地翻译探针](ENGLISH_TRANSLATION_PROBE.md)；没有产品准确率、移动延迟、内存或真机验收。不能把示例量化大小当本模型实测，也不承诺iOS键盘扩展可常驻百MB级模型；需单独验证扩展资源、Jetsam与低内存恢复。

权重许可与运行库许可分开。OPUS-MT中英权重**不能写成Apache-2.0**；正式选用前固定revision和SHA，并保存模型作者、来源、CC-BY-4.0文本及转换/量化改动说明。当前没有增加模型权重或新第三方SDK。

## 验收与接续

已实际运行：JDK17.0.20通过`--release 8`编译策略与合成测试；同一`test_android_learning.sh`入口通过。覆盖默认关闭/模型缺失/不合格字段、停顿/句末、有界最新片段、跨会话/模型/开关的旧结果、重复回调、取消、Unicode形状与时钟上溢。合成英文仅在测试源码中，不进入产品推理，也不是翻译质量验证。

接续顺序：

1. 相同合成句集跑真实本地模型基准，记录译文质量、冷/热启动、RSS、耗电和按键延迟；完成模型许可与固定包校验。
2. 宿主提交/生命周期接缝已加入，尚需接实际模型的独立worker与轻量英语条；同时为续词联想单独验证引擎能力。模型不可用时保持正常输入。
3. 验证乱序结果、同框重启、私密/搜索、撤销/外部改文；连续输入而不收藏时不得产生个人数据写入或R2操作。
4. 接现有收藏/导出和未来加密同步；验证点击所见、重复点击及换句期间的不可变快照。
5. 逐平台验收。Android/桌面结果不能代替iOS扩展的资源和系统限制验证。

### 共享核心提交来源契约（接续候选）

核心候选选择不必都是普通解码文本：个人短语、词库或新增规则也可能通过同一个select/CommitCandidate上屏。新JSON `commit_source`采用请求内来源，非空提交分为`engine`与`saved_data`，无提交/空串为`none`；错误保留原错误形状，没有上次来源。None引擎索引的个人扩展（即使与引擎同文字）及personal_commit标为saved_data；仅重排既有引擎行的规则仍保留engine映射。字段不改变正文、排序、generation或FFI ABI，旧宿主可忽略它。

Android核心提交仅接受严格字符串engine的当前ticket；缺字段、null、错误类型、未知来源及saved_data仍正常上屏，但清空伴学上下文。直接手打fallback/标点独立保留原有来源。这样可以排除经候选展开的个人资料，而不仅是资料面板插入。字段是本地受信任核心提供的来源提示，不是密码学证明。实际模型/worker/启用UI仍未接入。
