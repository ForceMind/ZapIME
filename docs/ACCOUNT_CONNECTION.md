# Android 服务器与设备连接

PR #63 已合入手动设备身份验证、加密保存连接、再次检查和移除本机连接。源码 3b0ce4f 的新 APK、API28/35/36 本机合成探针及真实 PostgreSQL 测试均通过；固定下载与 SHA 见[试用说明](ANDROID_TRYOUT.md)。本功能尚不上传词库、短语、收藏或剪贴板，也未绑定资料库的同步队列；不是完整的账号注册、跨端配对或数据同步。

## 使用流程

1. 按[服务器部署](SERVER_DEPLOY.md)部署支持`GET /v1/session`的ZapIME服务，配置有效的HTTPS证书。填写根地址，例如自己的`https://服务器域名`，可带端口，不附加路径、查询或账号信息。
2. 使用一键安装器时，首个设备凭据已保存于服务器 root 专用的`/opt/zapime/owner.json`，从自己的受保护终端取出并私密转移到手机。为已有设备重新授权使用`sudo zapime recover-device <设备UUID>`，保管这次新输出的JSON；旧令牌立即失效，原owner文件不会自动改写。直接运行服务二进制的开发者才使用`zapime-sync provision '设备名称'`创建独立账号。凭据不要发到聊天、Issue或日志；设备令牌不能解开E2EE密文。
3. 主App打开“服务器与设备连接”，填写地址并粘贴凭据，点“验证并保存连接”。客户端只发送一次显式身份检查，核对返回的协议、账号、设备、角色与到期字段，成功后用Android Keystore加密保存。
4. 重新打开只读取本机连接，不自动联网，也不把保存过的状态当作当前授权仍然有效。点“检查已保存连接”才重新验证；到期或撤销会报告失败，现有个人资料不受影响。
5. “移除本机连接”经过明确确认后只删除本机连接凭据与账号索引，保留个人资料和独立的E2EE材料。它不会撤销服务器上的设备；更换账号或服务器需先移除旧连接，个人资料不会自动合并或上传。

老服务缺少此接口会返回不支持提示，需要升级服务；没有HTTP或忽略证书的回退选项。域名示例不代表ZapIME已购买域名或已在用户服务器部署。

## 数据与网络边界

- 仅主App手动操作使用`SyncWorker`，不走键盘、语音或SQLite输入worker。启动页面只读本机密文，无后台轮询、应用层自动重试、请求正文或个人数据上传开关。
- `SyncHttp`只向用户明确填写的规范化HTTPS根地址请求`/v1/session`，使用平台默认CA与主机名验证，不跟随跳转。响应最大4096字节；连接/单次读超时至多5秒，读取循环有12秒预算，DNS解析仍由平台实现，不占输入线程。
- `GET /v1/session`只读PostgreSQL设备授权信息，不读写R2对象、不改资料修订或游标，不返回令牌或密钥。每次重新查数据库，不把缓存会话当作持续授权。
- 账号UUID索引是本机非秘密元数据。服务器地址、设备令牌和身份结果保存于`sync-connection-*`密文与独立Keystore别名；原`sync-material-*`文件、别名、AAD与格式保留。没有明文/SharedPreferences凭据回退；缺少包装密钥时不覆盖既有密文。
- 凭据页面禁止截图、禁用凭据控件状态保存/自动填充、请求不学习并掩码显示；离开页面清空输入框并取消请求标记，迟到结果不更新旧页面。已开始的本机原子保存可能完成。临时字节/字符数组按所有权清零，Java不可变字符串与TLS实现中的临时副本不能承诺立即擦除。
- 错误只映射固定代码，不显示原异常、授权头或服务器错误正文。普通个人资料归档不包含连接凭据。端到端恢复码、根密钥、新设备核对码与数据同步仍需另行接入。

## 持久账号保护（PR #66 / Issue #65）

保存凭据前，独立同步worker通过无输入会话的JNI只读查询本机SQLite v2的`sync_profile`。已有绑定与凭据账号不符，或schema/绑定损坏，拒绝保存并保留原连接。缺少数据库不会自动创建，未绑定数据库也不会因保存凭据自动绑定。移除连接不会解除数据库绑定，更换账号的独立资料库迁移仍未实现。该查询只检查版本与绑定元数据，不是完整数据库完整性审计，也不能代替未来每次上传/认证应用的事务内账号校验。最终源码 7466514 的 Rust 三系统测试及 API28/35/36 实际 JNI/连接保护五项均通过，见[原件](evidence/profile-guard-20261029/README.md)。固定试用包已更新到该源码。

## 验证范围

主机JVM用真实回环HTTPS验证生产传输类，测试CA仅在该独立测试JVM信任；产品没有测试证书或自定义信任逻辑。Android合成探针检查严格JSON/身份匹配、真实Keystore命名空间隔离、本机保存/切换保护、主线程IO拒绝和敏感Activity生命周期，不把合成身份当实际Android HTTPS成功。服务器的新身份测试要求真实PostgreSQL；本地缺库的SKIP不算通过。

产品新增INTERNET且禁止明文网络；原“APK无网络权限”适用于其固定旧源码，不能继续当本版结论。新三API输入/语音门禁在受保护的临时CI模拟器用IPv4/IPv6 OUTPUT owner规则拒绝产品UID的全部网络并记录`offline-uid.json`，退出只删除本轮规则；不在个人设备执行或接管既有规则。三API实际执行成功，精确源码、原件与限制见[证据](evidence/account-connection-20261029/README.md)。
