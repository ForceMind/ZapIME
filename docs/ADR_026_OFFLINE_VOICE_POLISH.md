# ADR-026 · 闪电输入法完全离线语义精简引擎（技术选型与安全门禁）

状态：**候选技术已研究；模型推理/下载/安装未接入，不得宣称智能改写已完成**。
对应 [#113](https://github.com/ForceMind/ZapIME/issues/113)。
日期：2026-11-16。本文描述后续工程验收，不改变已合并的保守语气词清理、原文切换和一次确认上屏。

## 目标与交互

用户说「嗯，就是那个，上周我们讨论的这个活动，我觉得因为人手不够，先暂时不要开发了」时，
希望获得较清晰的文字；但**不得将「不要开发」改为「尽快开发」**，也不得擅自删除日期、数值、
姓名、价格、链接和有歧义的陈述。

用户可在一轮本机语音录入结束后查看三个相互独立的预览：

1. **原文**：ASR 最终结果，不做替换；始终在会话中保留。
2. **保守精简**：现有 `VoiceTextCleanup` 规则，确定性删除独立语气词和完全重复的长短句；默认关闭。
3. **智能精简（未来）**：用户单独启用且本机模型已验证才能显示。若推理出错、语义保护未过或超时，**退回原文而不是插入未经核对的文字**。

没有任何一条自动向正在输入的应用提交内容；始终经现有 `VoiceCommitTransaction`
核对原输入连接、epoch、选区、隐私策略与用户点击。Android 密码/禁止学习输入框完全排除。
用户未明确选择前绝不自动传输原始语音或文本到服务器。

## 模型及后端候选（不是当前产品的性能证据）

- 首选初评 **Qwen3.5-0.8B**：公开权重许可显示 Apache-2.0。
  [Qualcomm AI Hub：Qwen3.5-0.8B](https://aihub.qualcomm.com/mobile/models/qwen3_5_0_8b)
  给出在 Samsung Galaxy S25 上的 GGUF Q4_0 约 **507MB**、4096-token context 和
  **37.7 token/s** 的参考值。这是第三方报告，未在 ZapIME、用户 S25 或本工程部署复现。
  参考官方模型页及
  [ggml-org 的 GGUF 转换](https://huggingface.co/ggml-org/Qwen3.5-0.8B-GGUF)；
  准确文件、上游 revision、量化器、GGUF SHA-256 和条款必须在导入前固定。
- 对照备选 **Qwen3-0.6B**：约 429–484MB 的四比特公开 GGUF 量化，
  [Qwen 上游](https://huggingface.co/Qwen/Qwen3-0.6B-GGUF)
  许可标注 Apache-2.0。绝不把某个第三方的性能或质量数字当作我们的可验收指标。
- 运行时独立比较 **llama.cpp Android/CPU** 与针对 Galaxy Snapdragon 的
  **Qualcomm QAIRT/GenieX/QNN** 路径。保留统一 `OfflinePolishEngine` 抽象与安全契约，
  但当前尚无模型、JNI、CPU/NN 加速实现。运行时 ABI、模型架构兼容性、许可证、分发权和
  执行线程先经过单独审计，不直接复制外部项目或动态加载不受控二进制。

初始模型不打入通用 APK。用户**显式**从合法来源选择模型文件，独立进程/worker 对 APK
固定可信清单的确切字节长度和 SHA-256 做全量校验；导入失败不覆盖之前的有效版本。
模型与普通个人资料备份分开。无效/缺失模型直接禁用智能档，现有 X-ASR/VoiceKey/拼音
完全不受影响。第三方量化文件不能仅凭名称相同或模型库许可就视为完整可信。

## 生命周期和资源边界

- 只有 **ASR final** 到达且取消 token/epoch 未变后才提交本机润色任务；
  不在 `onStartInput`、拼音输入线程、UI 主线程、同步线程或云端运行。
- 先完成语音原生会话的 stop/finish/close；不得因润色令 VoiceKey 30 秒 stop
  deadline 延长。限制模型并发为 1，允许用户即时取消，模型退出/资源回收完成前不复用槽位。
- 第一版限制输入 **不超过 512 Unicode 码点**、固定上下文与输出 token 上限，
  以及独立 **10 秒** 的用户可取消预算。超过预算、低内存、后台/私密状态、初始化失败、
  JNI 异常或结果与原文不一致时，立即保留原文并显示可理解的失败理由，不做云端回退。
- 冷启动、首 token、峰值 RSS、模型载入、CPU/NPU、能耗及用户可见总延迟必须
  分别实测；不能拿 Qualcomm 标称速度或主机 CPU benchmark 充当产品结果。
- 生成过程中禁止存储/上传原文、token、prompt、改写草稿到日志、崩溃报告、R2 或后台服务。
  仅本轮内存持有最多原文、保守精简和经验证的智能候选；取消/换框清空。

## 非语义保证的输出门禁

下列是**必须拒绝明显错误的最低检查**，不是声称自动保证语义：

- 必须为单一纯文本，不得包含思考过程、特殊模型角色标记或执行指令；
  非空、有限长度、规范 Unicode，不得超出冻结的输出预算。
- 对原文和候选抽取数字/金额/百分比/日期/时间、否定与命令边界、引号内完整字节、
  URL/邮箱及人工标注的姓名/专有名词，要求同序且不新增、不遗漏、不重排；
  无法可靠识别时保守拒绝并退回原文。
- 不允许根据模型输出操作输入法设置、剪贴板、网络、文件或当前编辑器。
  模型只返回一个候选字符串；确认上屏仍必须经过既有一次性事务。
- 质量评测针对完整冻结合成集，至少包含重述纠结、连续口癖、双重否定、医学用量、
  数字币价、多个金额、专名、日期、否定转肯定、前后矛盾、不完整语句、中英夹杂、
  方言和英文；记录原始输出、用户标注与各类错误率，不凭单个漂亮例子宣布可用。

## 分阶段交付标准

**P0（现有）：** #114 Android 本机保守精简+双预览+默认关闭；新增
[#116](https://github.com/ForceMind/ZapIME/pull/116) 实际安装 APK 的 Java 清理/偏好测试，
并与真实 VoiceKey 和 X-ASR CI 链路关联。两者不是 LLM 推理。

**P1：** 确定模型 revision/量化+许可证，写可复制的离线模型导入/签名清单；
在开发环境和一台经允许的 Galaxy S25 实测内存/输出质量，不进行自动切换。
原文及安全退回先行，失败归档不存个人文字。

**P2：** 独立 native worker + 可取消的本机模型推理、输出门禁与第三预览。
端到端用户点击测试：录音→模型识别→本机润色→三种预览切换→单次插入；
切换输入框、取消、权限改变和超时不得写入。Android API28/35/36 和真机分别验证。

**P3：** 完成定量对照和许可审计后，再决定是否允许默认开启；
其前不能把「语义智能润色」称为已发布功能或把实验 APK 当稳定发行。
