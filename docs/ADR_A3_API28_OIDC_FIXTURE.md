# ADR · A3 一次性 API28 OIDC 回跳验收

2026-11-24。用户已明确批准 A3 独立 GitHub 作业在全新 API28 模拟器中添加本轮合成 CA 和 `.test` 域名映射，结束后核对清理。Astra 已审查独立验收边界。原 [ADR-023](ADR_023_ANDROID_SYNC_HTTPS_CI.md) 的适用作业和脚本保持独立。

- 仅隔离 GitHub 作业和本轮全新 AOSP API28 `userdebug`、`writable-system`、`wipe-data`、`no-snapshot` 模拟器。写入前核对工作流、数字 run/attempt、专用 emulator 序列、qemu、API28、root 与 SELinux Enforcing。
- 只在工作副本中为两个固定 `.test` 域做本机映射，使用本轮独有的 443 反向端口和只绑定 runner 回环地址的真实 OIDC 提供方。确认端口、域名和 CA 路径未被占用。原始 hosts、CA 哈希清单和 reverse 清单在事务前后比较；清理逐项只撤本轮内容。
- 测试 APK 单独签名，沿用平台 TLS 与域名校验，不使用测试信任配置。固定验证前、移除 CA 后都由 App 发起 TLS 请求，并在域名和映射可达时观察证书拒绝。测试证书私钥、授权码、令牌及页面内容不进入参数、日志或 artifact。
- 两项成功分别记录。第一项是系统从正确 HTTPS 域取得本轮 `assetlinks.json` 后，把实际 APK、签名与回跳域验证为关联。第二项是实际系统浏览器从真实合成账号授权页面通过 HTTPS 回跳，测试 App 校验本次 `state` 和授权码、使用 PKCE 换令牌，同一 Go 校验代码验证服务签发的专用令牌。人工选择回跳处理器、由 ADB 注入回跳或单测通过都不能代替第二项。
- 同一隔离作业分别运行协议探针和从主 App Java、资源及清单构建的 test-only APK。后者经主页面进入「账号与同步」并实际点「仅登录」，以正式代码完成系统回跳和账号查询，再检查页面显示实际绑定账号、设备待授权及同步已关闭。签发者把这一路账号查询交给实际 Go HTTP 处理器和同一作业的隔离 PostgreSQL。
- 设备协议以独立 test-only instrumentation 继续。浏览器阶段与「仅登录」断言完成后，夹具仅在同一临时 HTTPS 进程把本轮合成身份交给测试。申请与领取用产品 Android 实现经真实 TLS 送入生产 Go 路由和同轮隔离数据库。已有 owner 在夹具中单独批准和撤销。Go 确认领取后才丢弃响应，并验证 Android 重新读取暂存、以原凭据查询设备会话、随后在撤销时被拒。报告区分登录、暂存与设备协议，也逐轮检查资料请求为零。
- 自动同步另跑一轮，同一授权的临时模拟器条件和固定域名。重新安装 test-only APK，合成会话经过实际 HTTPS 检查后，通过原生存储准备一个快捷短语和关闭状态。用实际账号页确认开关，观察真实 Go/PostgreSQL 修订、页面回执、SQLite 持久 ACK 和独立主机客户端解密。只有前台轮转发本轮资料接口，真实 OIDC 轮继续拒绝资料请求。资料轮独立生成 CA、核对前后 TLS 拒绝并清理。
- 同一前台轮隔离验证同步服务通路中断。仅临时撤回并恢复本轮原有的 `tcp:443` 映射，每次操作重新核实模拟器及映射归属，并核对其它映射与初始清单。失败期间通过实际账号页和原库保留证明校验，恢复后通过主 App 实际前台入口核对只提交一个新增修订。默认网络变更回调单独验收。
- 默认网络回归只在候选镜像实测默认 Wi-Fi、可用传输仅 Wi-Fi 与蜂窝且两个原始开关均能读回时执行。每次用 stock `svc` 操作前核实本轮模拟器，暂关并在 `finally` 还原原开关，反向端口、域名与 CA 保持。独立 test-only 观察器核实同一账号 Activity 持续前台、系统实际无默认网络与回调恢复，并用原生产 JNI 创建唯一合成记录。禁止调用产品内部同步触发。原库回执、独立接收、系统开关回读和实验标记清理均是门禁。
- 中途关闭验收仅对第四个合成 POST 的固定操作，在实际 Go 提交之后短暂保留响应体，使用有界 JSON 前导空白维持读取。验证真实页面关闭早于连接取消且真实 ACK 未送出，原冻结请求和 SQLite 游标保持。重新开启后须以实际认证回声核实原操作，不能再 POST。请求与摘要只用于隔离夹具比对，公开报告保留通过状态和计数。
- 已有资料的 A 退出后，通过实际系统浏览器登录未登记设备的 B。两个合成账号共享同轮隔离服务数据库。Go 仅在专用工作流触发的本地测试库路径内绑定两个主体并核对账号状态，无需新建公网服务。先后对比系统账号页、会话/描述/资料请求计数及 Android 原库与 KeyStore。公开报告只写通过状态、次数及环境清理结果。
- 报告只记录固定原因码、步进状态、数量、源码与公开指纹。两轮分别完成前后 TLS 拒绝、CA、hosts、reverse 和 APK 清理。任何失败均运行清理并保留原失败。Android 正式凭据晋升、产品界面领取、完整产品 APK 和部署后的原厂公网信任仍分别验证。
