| 测试 | 结果 | 证据范围 |
| --- | --- | --- |
| 过期候选点击 | 通过 | zapime-core 集成测试拒绝旧 generation |
| 非法键值、越界候选 | 通过 | 无状态变更 |
| 两连接旧修订覆盖/删除复活 | 通过 | SQLite IMMEDIATE 事务，旧 revision 被拒绝 |
| 操作幂等、同 ID 参数替换 | 通过 | 相同请求只保留一次；不同请求拒绝 |

| 剪贴板过期误删收藏 | 通过 | 收藏保留，临时记录写墓碑 |

命令：cargo test --workspace --locked；cargo clippy --workspace --all-targets --locked -- -D warnings。当前共 20 项集成测试（core9、data8、crypto3）通过。测试输入和恢复数据全部为合成内容。

## 2026-10-22：原生边界与独立同步服务

- 新增有界 C ABI：错误/过大缓冲输入在读取前拒绝，跨线程句柄不可访问/关闭，释放后句柄拒绝；Windows DLL/COM 引用计数和锁下溢、未知 CLSID 与未激活吞键拒绝通过原生 CI。iOS 专用 Thread 原生桥接测试通过。
- PostgreSQL 实测幂等、并发旧修订冲突、删除墓碑防旧版本复活、分页无缺口、账号隔离、成员越权拒绝、撤销后已认证 actor 拒绝、凭据轮换后旧 actor 拒绝、令牌仅保存摘要，以及配额拒绝不留下部分修订。
- HTTP 实测未知明文字段、过大请求、追加 JSON、错误版本和游标拒绝；新数据库连接仍读取同一密文，证明不是内存仓库。
- Docker 灾备实测见 CI 39655004350：真实 Rust AEAD 密文交换、撤销、备份、新空库恢复、新进程恢复密钥/归档并认证解密。恢复材料只在私密临时文件，未传服务器或日志；测试后销毁随机独立 Compose 项目。
- govulncheck v1.9.0 初扫发现 x/text 传递依赖 GO-2026-6629（修复 v0.41.0）与 GO-2026-5970（修复 v0.39.0）。提升到 v0.41.0 后本地扫描未发现已知漏洞，CI 加入相同固定扫描器。
- 本地协议 fuzz 3 秒共 29440 执行，无失败。

未覆盖：恶意服务端的历史回滚检测、完整设备核对码配对/密钥轮换、OS 密钥托管、四端客户端、生产 TLS/速率/负载、真机安全字段和独立第三方审计。服务端无法验证密文标签，客户端必须先认证解密并比较正文与外层元数据；访问凭据不等于 E2EE 密钥。
