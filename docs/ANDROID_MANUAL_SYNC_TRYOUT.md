## 服务器一条命令

在自己的受支持Linux服务器终端执行以下**固定版本**安装命令。它会交互询问域名、私有R2桶和桶级凭据；DNS指向及80/443可用性由服务器管理员准备，未替用户修改DNS或购买域名。凭据不要发到聊天或提交Git。

```sh
curl -fsSL https://raw.githubusercontent.com/ForceMind/ZapIME/e3c4da10b5f90917c2c8d17aeb8fc382f78ec4f9/deploy/install.sh | sudo bash -s -- --ref e3c4da10b5f90917c2c8d17aeb8fc382f78ec4f9
```

未合并main期间不要把下载版本和 `--ref` 混用。已有反向代理或恢复旧服务器的情况按[部署文档](SERVER_DEPLOY.md)单独选模式，保留原配置、数据库密码与成套备份。schema3升级不能通过换旧镜像降级。服务一键安装、重复安装和全新DB/对象桶恢复已在隔离CI验证；没有访问用户服务器、Cloudflare账号或实际公网证书的记录。

首次设备凭据由安装器写入服务器root专用 `/opt/zapime/owner.json`。在主应用“服务器与设备连接”输入最终HTTPS根地址和这份凭据，实际验证并保存；设备令牌不是E2EE密钥。当前仍是管理员CLI分配设备，不是完整图形账号注册/双设备配对。

## 集中试用流程

1. 先确认九键/全键、主题、触感、中文/英文和原有资料仍正常。离线语音继续按[双引擎试用说明](DUAL_VOICE_ALPHA_TRYOUT.md)准备所选模型，X-ASR仍为默认。
2. 初始化本机个人资料页，再进入“准备本机加密同步”。首次空账号由管理员明确创建；已有设备使用原密钥恢复文件与恢复码。导出恢复文件并核对恢复码，这个文件只含密钥材料，不含个人资料。
3. 在独立“核对服务器密钥”页检查公开身份。只有没有同步历史的空账号可首次登记，其他设备应导入同根材料后核对；不同密钥或legacy历史会停止，不自动换根。
4. 在“手动同步个人资料”核对所显示的服务器、账号、设备和SHA摘要，再明确确认本轮。它包含待同步的词库、候选、短语、收藏、已保存剪贴板及删除。没有后台轮询，每次最多16项上传、前后各2页；达到上限可稍后再次手动继续。
5. 若有第二个测试设备，先备份其资料，再用服务器授权的member凭据、同一密钥恢复材料接入。分别添加合成收藏、手动同步并刷新面板；新增词库/候选请重新进入输入框验证。当前组字缓存不热更新，不强制清空组字。
6. 断网继续本地输入和编辑，恢复网络后手动执行一轮；只观察自己保存的合成测试资料。不要在真实业务资料上主动制造冲突或清库；冲突会停止并保留原内容，解决/历史迁移UI尚未完成。

退出或取消是协作请求，已经提交的网络操作/本机事务可能完成。未确认请求仍保存原密文，后续手动重试由真实ACK核对；不会生成另一份请求或把ACK当作拉取游标。
