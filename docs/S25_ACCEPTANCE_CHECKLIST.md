# 三星 S25 一次集中验收

本单把安装、候选、键盘、语音、本机恢复、只读同步预览和显式同步串成同一轮。当前所有手机项目仍为 **NOT RUN**：先选择符合签名与来源核验的 ARM64 开发候选，再由设备所有者集中执行。源码 Alpha 压缩包不是安装包，新功能不能借旧 APK 冒充通过。第11项的本地状态页已通过 [PR #104](https://github.com/ForceMind/ZapIME/pull/104) 合并主线（同源码模拟器门禁全部通过），但**仍须在包含该功能的对应APK上进行S25物理设备验收**。不得在旧候选里寻找不存在的页面。

## 一次准备

1. 选定一份已经下载核验的 ARM64 产品 APK，记录 source commit、APK SHA256、签名证书 SHA256、模型清单，以及 S25 型号、Android/One UI、存储、网络状态。固定候选身份见[候选试用](CANDIDATE_RANKING_TRYOUT.md)，旧版说明只代表各自固定字节。只装产品包，不装 CI test-only 包。
2. 先在旧 App 分别保存个人资料备份、同步密钥恢复文件及各自恢复码；它们用途不同。独立保留原文件并在安全环境验证可读。签名不一致时保留旧 App 和资料；正式签名、覆盖升级或卸载保留尚不能假定通过。
3. 使用合成文字和专门测试资料；不在唯一真实资料上验证空库恢复或冲突。用户手机不运行 GitHub 模拟器专用清库、root、临时 CA、UID 防火墙或全局日志脚本。
4. 候选 8M 随包固定，语音 X-ASR/VoiceKey 各自显式导入可信模型；先记录默认 X-ASR，再测试可选 VoiceKey。准备后开启飞行模式验证离线功能。

## 顺序执行并保留失败

| 顺序 | 操作和通过条件 | 状态 |
| --- | --- | --- |
| 1 安装/回退 | 包/签名身份与所选候选一致；已有资料保留；遇签名冲突停止升级并保留旧环境 | NOT RUN |
| 2 基础输入 | 全键、九键、读音约束、数字/符号、英文、选区、连续退格和组合 emoji；独立编辑器正文与所选项完全一致 | NOT RUN |
| 3 候选身份 | 增强默认开启；空可信上下文保持基础顺序；先真实选择“你好”再输入 shijie；快速输入、按住候选、展开/点击、空格、九键读音后上屏均为当前所见项，无迟到替换 | NOT RUN |
| 4 焦点/生命周期 | 连续组字中隐藏/重开、切应用、切编辑器、转屏、光标移动及换系统输入法；保留应保留的组字，失效结果不进入新位置，退出后不继续录音/计算 | NOT RUN |
| 5 隐私边界 | 密码、禁止学习、无建议、搜索及隐私场景分别验证；旧上下文不跨字段；不自动保存输入、录音、剪贴板或同步 | NOT RUN |
| 6 布局/触感 | 浅深主题、系统和 App 触感各自关闭/开启、字号放大、横屏、小窗口及 TalkBack；记录实际触达/裁切/马达体验 | NOT RUN |
| 7 本机资料 | 仅显式保存合成短语/收藏/剪贴板；搜索、置顶、删除、期限、重新进输入框后的候选与资料一致 | NOT RUN |
| 8 本机备份恢复 | 系统文件选择器导出且读回，独立保存恢复码；在独立已初始化的空测试资料库真实打开原文件并恢复合成记录；错误码/篡改/非空库不覆盖 | NOT RUN |
| 9 双离线语音 | 对两引擎分别执行[同一语音子单](S25_DUAL_VOICE_CHECKLIST.md)：独立模型、静音、预览确认一次、取消/再录、焦点/权限/蓝牙、60秒；全部结果独立记录 | NOT RUN |
| 10 同步材料恢复 | 用另存的密钥恢复文件与对应码，经真实系统提供程序打开；同根可继续、异根/错码拒绝；本机资料备份不能冒充密钥恢复包 | NOT RUN |
| 11 本地同步状态 | 在已准备的合成测试资料库中，从“手动同步个人资料”打开“查看本地同步状态”；用超过40条合成记录验证每页最多40条、下一页替换和从头刷新；只见类型、ID、修订及本机证据，不显示正文或标题；离开清页、迟到结果不恢复；不产生 HTTP 或新增待发操作，不将本页状态显示为云备份完成 | NOT RUN |
| 12 显式 HTTPS 同步 | 仅在已准备的测试服务/账号核对服务器、账号、设备和 key SHA 后逐轮确认；新建合成资料可上传/拉取；打开页面/键盘不自动请求，断网仍可本地输入 | NOT RUN |
| 13 失败恢复与退出 | 取消或离开后迟到结果不能改新页面；已开始事务可完成须读实际状态；ACK不当pull cursor、冲突停止保留。最后切回系统键盘并检查无持续录音/崩溃 | NOT RUN |

第 8 与第 10 分别验证记录快照和同步材料，不能互相代替。当前没有用户可操作的清库/换根修复或完整配对/冲突解决界面时，记录为未支持；不通过删除真实数据来构造“成功”。第 11 只查看本机证据：上传0项或没有同步记录不等于资料已备份，本机服务端修订也不是云端实时确认。恢复/导入存量记录的首次上传仍未实现，按 Issue #77 继续推进，不把预览状态当作上传授权。第 12 只有服务和凭据已由所有者准备时执行；缺少服务则标 BLOCKED，并完成前面的离线部分，不要求提供聊天中的令牌或密钥。

## 统一记录

每个场景只记：候选身份、系统版本、场景编号、PASS/FAIL/BLOCKED、重复次数、固定错误类型、用户实际观察、是否恢复及恢复耗时。真实正文、录音、剪贴板、数据库、恢复码、密钥和凭据留在本机；秘密恢复页不截图。多次重复不是新语言样本，成功复跑不删除第一次失败。

冷热加载、首字、最后音频到定稿、完整输入可见延迟、P50/P95、峰值内存/CPU/温度/能耗分别测量并注明工具与样本数；主机 IPC 时间、模拟器帧或合成音 CER 不代填。条件不具备就标 NOT RUN，保留质量和故障记录。
