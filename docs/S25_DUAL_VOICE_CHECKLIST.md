# 三星 S25 双离线语音集中验收单

本页作为[S25一次集中验收](S25_ACCEPTANCE_CHECKLIST.md)的语音子单使用；安装、候选、备份恢复和显式同步只在总单统一准备。

目标：一次安装准备后，集中验证 X-ASR 与 VoiceKey，记录失败再统一修复。当前机型/自然人声/能耗项目均为 **NOT RUN**；模拟器、CPU探针和静音 AudioRecord 不替代本单。不预先推荐第二引擎。

## 准备一次

1. 记录候选源码、APK SHA256、Android/One UI版本、设备型号、剩余存储；先导出个人资料并独立保存恢复码。开发签名若不同，不能直接覆盖；不要删除唯一未备份资料。只使用本候选对应的构建及模型清单。
2. 在独立测试安装/资料环境验证迁移；日常手机不运行仓库中限定临时GitHub模拟器的清数据、撤权限、UID防火墙或全局日志脚本。
3. 原有X-ASR模型和VoiceKey模型各自显式导入。VoiceKey原始包由用户从说明中的官方来源取得，按固定版本/尺寸/SHA核对；ZapIME APK不附带其第三方权重。下载可达性和模型使用条件与作者源码许可分开。
4. 主App允许麦克风，在普通测试输入框启用ZapIME。记录所选引擎与模型版本/SHA，X-ASR仍默认。模型准备结束后开启飞行模式，保持Wi-Fi和移动数据关闭。

## 两引擎各执行一遍

| 场景 | 操作与通过标准 | 状态 |
| --- | --- | --- |
| 独立模型 | 仅安装所选模型时，从长按空格及工具入口进入语音；另一模型缺席不拦截。切换引擎后重新开始会话 | NOT RUN |
| 空/静音 | 不讲话录音再停止；无文字时不得可确认插入，不凭静音样本推断VAD能力 | NOT RUN |
| 普通短句 | 输入“今天下午三点，我们在图书馆见面”；预览、停止、确认后正文恰插入一次，期间不得自动上屏 | NOT RUN |
| 数字与否定 | “不是十五元，是五十元”“十一月六日”“不要取消这个订单”；逐字保留参考与识别，记录所有差异 | NOT RUN |
| 中英术语 | “打开 Wi-Fi 设置”“明天讨论 Android 项目”；不把混说例子更换为已经识别正确的句子 | NOT RUN |
| 连续/停顿 | 短句、停顿、较长句；没有新partial时旧预览不能反复清空，停止后的定稿与确认分开 | NOT RUN |
| 取消重录 | 加载中取消、录音中取消、停止后取消、再录；取消结果不得迟到上屏，新会话不能继承旧文字 | NOT RUN |
| 编辑器失效 | 录音/定稿时隐藏键盘、切换输入框/应用、移动光标或选中文字；原结果不能进入新位置 | NOT RUN |
| 隐私字段 | 密码/禁止学习字段不开放语音；已有普通输入结果不能跨到隐私字段确认 | NOT RUN |
| 权限与设备 | 撤销麦克风权限后正常输入仍可用；重新允许可再录。外接/蓝牙麦克风切换及系统静音情况单独记录 | NOT RUN |
| 60秒和慢机 | 长录音达到边界、后台压力下停止/取消；不得静默丢音、无限等待或持续后台推理。记录错误与实际恢复时间 | NOT RUN |
| 模型替换 | 导入同版/损坏包、存储不足、导入中离开及重启；失败保留原有效模型，不依赖另一引擎兜底 | NOT RUN |
| 输入回归 | 九键/全键、候选、明暗主题、系统触感关闭/开启、退格、资料搜索/插入、备份恢复和切回系统输入法 | NOT RUN |

无需上传个人聊天、剪贴板或录音。默认只记录引擎、模型SHA、计数、耗时、错误类型与系统版本；如果要保存自然人声/识别正文，先由用户明确选择范围并留在本机。

## 公平测量一次

使用同一台手机、同一批非敏感语料和相同PCM。离线固定音频顺序重放两引擎，先不并行争抢CPU；自然录音另列，不能将两次说话差异当模型速度差异。冷启动与热启动各自单列，预先固定样本清单、轮次、线程数和喂入方式，不按识别结果删句。

| 指标 | 记录口径 |
| --- | --- |
| 准备/校验 | 导入、文件SHA校验与模型加载分开计时 |
| 首字 | 从实际开始接收音频到首个非空partial；无partial作为失败/无样本保留 |
| 定稿 | 最后音频/点击停止到final可供确认；上屏另计 |
| 文字质量 | CER=(替换+删除+插入)/参考字符数，分母加权；保留失败句，不用100%-CER称准确率 |
| 资源 | 峰值内存、CPU、温度/降频与能耗；记录测量工具和未覆盖项 |
| 分布 | 各组样本数、成功/失败数、P50/P95；少量样本不作稳定手机性能结论 |
| 限制 | RTF是计算时长/音频时长，不是首字或停止到定稿延迟；合成音不是自然人声准确率 |

模板字段：`source_commit, apk_sha256, device, os, engine_id, model_id, model_sha256, threads, feed_mode, cold_or_warm, reference_set_sha256, samples, failures, p50_ms, p95_ms, cer_sdi, peak_memory, cpu, energy_method, limitations`。

只有以上实际结果与许可、签名、升级材料齐备后，才决定推荐引擎或提升发布层级。此验收单本身不是通过记录。
