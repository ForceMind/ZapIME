三轮分别复用相同12条音频，每轮参考字符数相同，输出在各自环境内相同。下表是每一轮的`唯一12句`汇总，不把三轮重复当36条独立语音，也不合并两套TTS音频：

`speech-v1`只规范NFKC/大小写/标点/空白；单位为Unicode码点，英文也按字母计数，详见[评分定义](../../VOICE_QUALITY.md)。不是WER，也不是“中文真人准确率”。12个WAV中10个SHA在两合成器之间不同，两环境CPU/构建也不同，不能把分数差直接归因某一个因素、挑较低值宣传或平均成总体识别率。合成器和线性重采样本身也可能引入不自然发音。

实际坏例包括：

- 本地日期“十月”变“十一月”；金额句、姓名和混说有明显错误。
- CI姓名句“林小雨和陈向阳约好明天见面”只得到“好民间见面”，计10个字符编辑错误。
- CI混说“请打开WiFi，然后检查USB连接”变为“天啊六二七， 然后天杀 U S B 连篇”，计10个字符错误。
- 否定和自我纠正两条在两环境的规范化视图均0错误；不能从这两条外推口音/自然语音表现。

模型为同一固定X-ASR流式INT8、sherpa-onnx 1.13.8、numpy 2.5.4、CPU两线程。加载分别约1.697秒/1.394秒；每轮不按真实时钟馈入的总解码约3.777–4.043秒/4.153–4.290秒，包含每句1秒零尾块。Linux Python进程峰值RSS为324492/326584 KiB。加载不含先前导入和逐项模型SHA；这些都不是手机冷/热启动统计、麦克风首尾字延迟、耗电或自然语音验收。
