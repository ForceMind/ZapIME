# 候选质量 v3：先冻结，再运行

本切片的语料为专门编写的合成用例，没有读取真实输入、剪贴板或录音，也没有据词库候选或模型输出选择答案。全部预期是用例作者指定的续接目标、拼音读音或显式个人偏好；它不是自然用户分布或独立人类标注集。

`integrations/candidate/tests/quality-corpus-v3.json` 包含独立的64条用例，SHA256 `70b1aa8209e376b7ca8d9c5aab39b3a4be3bcb129a09ff556d8dd086947593f1`。旧v1/v2的34条、修字历史和结果逐字节保留，不能与v3合并后宣称新增98条独立语言样本。同音词对和跨布局用例也有相关性。

| 分类 | 用例数 | 冻结的验收意图 |
| --- | ---: | --- |
| 同音词 | 24 | 上下文指定不同目标；不保证模型一定改善 |
| 日常词 | 8 | 常见输入的基础与重排对照 |
| 九键 | 8 | 同时保存完整拼音和独立可核的T9编码 |
| 补全 | 6 | 输入少于目标完整读音；目标不在可见页也记缺失 |

| 个人规则 | 6 | 3条固定候选、2条合成短语、1条个人词典；按显式偏好评估，不当自然语言准确率 |
| 上下文边界 | 6 | 2条空上下文、4条恰好64码点，含补充平面字符；人工填充不当自然语句质量 |

冻结指标：所有64条均进入每模式分母；首选/前三/MRR、候选缺失、改善/退步、首选挽回/损害沿用版本化配对统计。额外按实测结果分别归因目标不在可见页、目标在页但不在评分池、可评分目标改善/退步/不变；个人规则和各边界单独分组。缺失或受保护目标不能改标签，也不能从分母删除。固定槽和所有候选ID/文字必须保持，任意破坏均拒绝整轮成功。

上下文由主机runner直接传入native模型。空上下文是低层诊断，Android产品已有空上下文保护；64码点检查也不证明Android的焦点、隐私、失效或截断生命周期通过。计时仅主机IPC/native，资源仅scorer进程；不当手机延迟、内存、能耗或真实准确率。

本语料提交时未运行v3词库/模型推理。先固定语料与指标提交，再让runner锁定其SHA和提交，并执行真实生产词库/核心/native评分。最终报告必须保留所有失败，并记录固定运行库、词库、模型、核心、runner和语料身份。

冻结前独立只读复核：64条预期与拼音无客观拼写错误，8条九键逐字映射一致；4条长上下文均64码点，补充字符用例121个UTF-16单位。复核没有查看词库候选或模型输出；目标是词级续写，不要求已经组成完整句子。
