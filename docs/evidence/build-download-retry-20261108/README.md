本切片基于 `901330f400821913be0d733cc9b16a1d232f6f22`。原#95固定源码的模型与词库GET均实际遇到HTTP504，使APK和质量门禁未执行；本目录 `before/` 保留原安全日志、精确源/job metadata及原始字节摘要。响应来自哪个服务器/代理、具体失败模型成员并未由日志证明，不能据它推断唯一网络根因。#96的另一份504由前序证据提交807ef7f保留，本切片不重取或重跑。

在修改实现之前新增合成回归并对原调用者运行：7项中既有完整性/离线边界2项已通过；模型504、词库504、离线归档504及中途连接重置的恢复用例均ERROR，最终失败仅执行1次导致另1项FAIL。原输出保留；不是用真实模型或反复CI下载试成功。新的helper测试在实现前一并冻结，之后用于验证次数、单调预算、Retry-After、永久错及可验证网络错误分类。

既有网络参数为模型/语音60秒socket timeout、词库120秒；原代码没有整文件墙钟总预算。保留原CI作业/离线导入10分钟step时限和这些socket上限。新设计只重试相同固定HTTPS GET，至多3次；只接受明确暂时性HTTP429/500/502/503/504及可分类网络异常。错误校验、HTTP4xx（429除外）、不支持协议/功能状态、TLS证书错误、磁盘错误、离线缺失均立即失败。每轮独立临时文件从零开始，不拼接部分响应、不更换镜像或放松SHA/长度/许可。

新增单调重试预算拟为模型/语音180秒、词库360秒，退避1/2秒且尊重可解析Retry-After；不得为赶预算而提前重试。剩余预算约束连接timeout、流读取边界和发布前检查。Python/操作系统已进入的DNS或阻塞socket调用不能由这个同步封装硬杀，因此不把调度预算夸称物理强制墙钟终止。数据流、完整性与临时文件保护仍必须在任何最终失败时生效。

本目录第一笔提交只冻结原失败与测试；之后的实现和最终本机结果另行记录。原失败不会改写为通过，不自动重跑#95/#96。
