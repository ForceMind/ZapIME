# Android 本机资料加密备份

本功能为候选源码，首次真实三API/JNI/系统文件提供程序结果待CI。固定已验收APK仍见ANDROID_TRYOUT，不把本页的实现状态等同已发布。

## 范围

备份个人词库、候选规则、短语、永久收藏、剪贴板及逻辑删除记录，快照与现有schema_version=1开放归档一致。恢复后临时剪贴板仍按原绝对期限过期，永久收藏不跟随其清理。

这是本机记录的加密快照，不包含设备访问令牌、云同步根密钥、账号绑定、操作/收据/游标、失败页、语音模型或键盘设置。它不能恢复云账号密钥或代替设备配对，不会开启联网。原明文入口仍保留，SQLite本身仍未整体加密。

## 使用

1. 主App打开“管理资料与备份”，等待本机资料初始化完成，进入“加密备份与恢复”。移动端首版明文归档最多4MiB，加密文件最多6MiB；接近上限时可能因保守的结构开销预算提前拒绝，不截断资料。
2. 点“选择位置并创建加密备份”，在系统文件选择器选择自己控制的位置。只把密文交给提供程序，写入、关闭并重新打开读回字节一致后，才显示43字符恢复码。
3. 将恢复码抄写，或点“复制恢复码…”阅读风险并确认后，粘贴到可信密码管理器，与文件分开保存。复制设置系统敏感标记，但不能阻止所有其他应用读取；不是外部保存证明。切换应用会清除本页显示与输入，不会自动清除系统剪贴板。可返回点“清除本次复制的恢复码”：只在当前标签及内容摘要仍匹配时清除，核对时不匹配则保留当前内容（系统读取与清除不是原子操作）；页面销毁后请从系统剪贴板手动清除。留在本页时可抄写后输入核对，核对也不是外部保存证明。若恢复码丢失而仍有原资料，可重新创建另一份备份；没有恢复码无法解密对应文件。
4. 恢复时先在全新安装中打开本机资料页完成正常初始化，再选择加密文件、输入其恢复码，点“验证并恢复到空资料库”并确认。只有没有记录、账号绑定、操作及同步历史的空库才可导入；不要删除绑定或修改数据库版本来绕过限制。
5. 认证、完整归档校验后，同一个SQLite事务检查目标状态并写入，已有内容不被覆盖。返回资料页会在设置worker显式重新加载原生会话记录再显示列表；全程不需要服务器。

## 实现与限制

KDF/SQLite/文件IO在独立备份worker，进程内最多一个执行、一个排队；不占输入、同步或UI worker。系统提供程序的读写、KDF及已经开始的恢复事务不能承诺即时中断；离开清除UI并失效迟到回复，已开始事务仍可能完成。返回资料页检查实际内容，不把离开页面当事务回滚。

系统SAF文件写入不具备本项目可控制的跨提供程序原子性，失败/中断可能留下不完整文件。本程序不自动删除用户选择的文件，读回一致也不保证提供程序今后永久保留它；请保留独立副本。原资料不会因导出而删除。

敏感页FLAG_SECURE，恢复码输入掩码、不自动填充、不保存视图状态并请求不学习，无自动复制到剪贴板。原生代码用byte[]传递代码，Rust密钥和代码/明文缓冲按所有权清零；Java不可变字符串、平台与解析器临时副本不能保证立即擦除。原文只在本机内存/既有SQLite处理，不写日志。

加密复用zapime-crypto既有v1恢复封装（固定Argon2id m32768/t2/p1与XChaCha20-Poly1305）；不接受文件自定义KDF参数。认证内层先带ASCII `ZapIME/local-records/v1` 与一个NUL字节，再接UTF-8开放归档。该用途前缀区分普通/同步恢复包，防止误导入后丢弃其真正同步材料。封装中的新随机备份密钥仅用于此独立文件，不读取/替换SyncSecrets材料；解密后不将它配置为同步密钥。格式源码和算法实现随仓库保留，便于独立恢复。

## 验证

本地Rust工作区87项、fmt/严格Clippy、JVM文件故障6项及Java产品/目标探针编译通过。新增Android探针将检查真实JNI快照/认证/空库恢复、非空与绑定拒绝、线程/长度、敏感页面、真实系统ACTION_CREATE_DOCUMENT导出并将实际提供程序字节恢复到独立空库，显式确认后的敏感剪贴板复制/清除与新内容保护，以及退出清除。这个组合不是正向SAF导入页面或真机验收；不修改用户主库来强行制造通过。

系统文件夹具仅由数字run/attempt+emulator序列验证的临时GitHub脚本传显式参数启用，测试只清理自己新建的合成资料库和文档。保留原输入、语音、权限、UID断网与退出门禁；结果后续归档于evidence/local-backup-20261030/。
